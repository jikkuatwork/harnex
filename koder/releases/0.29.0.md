# Harnex 0.29.0 — verification

Date: 2026-10-22. The agent release (summary of 0.22–0.29), documented and
with a website. The owner chose version 0.29.0. Publication (GitHub push,
tag, RubyGems) awaits the owner's go-ahead; this record covers the local
install and the site.

## Changes

- **Docs:**
  - `docs/lanes.md`, `docs/mcp.md`, `docs/agents.md` and
    `docs/upgrading-to-0.29.md`;
  - `GUIDE.md` now starts with lanes;
  - `TECHNICAL.md` gains a "Lanes and MCP" section;
  - the README links the site and docs.
- **Public examples** use generic model names (`openai/gpt-5.1`); no private
  gateway names remain in shipped docs or help.
- **The `gpt` agent ships in the gem** (`agents/gpt.md`). `harnex mcp install`
  installs it unless one exists; `uninstall` removes only an unmodified copy.
- **Gem metadata:** a new summary and description, plus documentation and
  changelog links.
- **Website** `site/`, built by `site/build.rb` from the docs and the live CLI
  help, deployed as a Holm app at https://harnex.zyt.app.

## Evidence

- Suite: **822 runs, 4,260 assertions**, 0 failures, 1 opt-in skip.
- **Installed:** `harnex --version` → `0.29.0 (2026-10-22)`. All 89 shipped
  files match the source, including `agents/gpt.md`. `harnex doctor` → ok;
  `integrations` (`claude_mcp`, `pi_mcp`, `gpt_agent`) all true.
  `harnex mcp install --dry-run` keeps the existing agent.
- **Site,** Holm app `holm_app_wQ4TB6JUhrTZ` on peer `zyt`, host
  `harnex.zyt.app` (generation 2):
  - `holm app validate --spec-v1` passes with 0 warnings.
  - Over HTTPS, all pages return 200, raw `.md` is served as
    `text/markdown`, `llms.txt` and `llms-full.txt` are plain text, and a
    missing page returns 404.
  - Holm injected the icons, manifest and `og:image`.
  - The service worker activated (cache `harnex-<build>`).
  - `HolmFeedback` loads; feedback project `6jyd3ya4` (private board).
  - Browser checks at 1440 and 1280 (dark and light) and 390 px (dark):
    every page fits 390 px with no sideways scroll, and there are no page
    errors.
