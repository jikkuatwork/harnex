# Harnex 0.25.0 — local-only verification

Date: 2026-10-22. Local install only (#87).

## Changes

- Pi workers never get harnex's own MCP tools:
  - `--exclude-tools mcp__harnex__…`, merged with the caller's exclusions
    (Pi >= 0.99);
  - allowlisted (read-only) workers get `--no-mcp` (Pi >= 1.0.4).
- Progress reads `now bash 12s`; generated lane names skip filler words.
- Evals lift the print-mode background ceiling; S6 accepts
  `tmux capture-pane`.

## Evidence

- Suite: **816 runs, 4,216 assertions**, 0 failures. Installed `0.25.0`;
  84 files match.
- Built commands on the installed Pi 1.4.0:
  - default:
    `pi --mode rpc --no-approve --exclude-tools mcp__harnex__ask,…,mcp__harnex__lanes`;
  - read-only: `… --tools read --no-mcp`.
- Live checks:
  - `harnex ask "What is 2+2?"` → `4` in 6s;
  - a delegated worker asked to list its `mcp__` tools answered "none".
- **Interactive Claude Code 2.1.308** (Sonnet, a tmux session through
  `harnex run claude`), asked to delegate `BENCH_SECONDS=200 bin/slow-bench`
  with the harnex MCP tools:
  - The `delegate` call showed live progress under the tool call
    (`working 59s · 3 tool calls · now bash`).
  - It moved to the background at about 2 minutes, and Claude replied that
    it would report when done.
  - Claude Code later announced `MCP task … (harnex/delegate) completed`,
    and Claude answered "The score is 4242" (run 3m39s). No subagent, no
    polling.
