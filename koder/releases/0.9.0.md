## Migration evidence

- Consumers must stop redirecting `--summary-out` merely to retain rich rows;
  tracked `.harnex/dispatch.jsonl` is canonical.
- Holm's 1,156 valid legacy rich scratch rows are retained for one-time import
  into its tracked stream; import and downstream queue/session rollup migration
  are Holm-side work in this release window, not a Harnex writer mutation.
- Mixed v1 thin, envelope-less rich, and v2 start/end rows are covered by tests.

## Long-run telemetry

No multi-hour or overnight workload was run. Candidate work used six successful
bounded implementation/audit dispatches plus one independent review; the real
source smoke lasted 34 seconds. The first source smoke failure was a caller-shell
credential environment mismatch, not a transport disconnect or source defect;
the one corrected attempt succeeded. Final installed-smoke telemetry will be
added after publication.

## What this verification did NOT cover

- Deleting real user events/output logs. Retention was exercised only against
  disposable `HARNEX_STATE_DIR` trees; the installed default will prune
  opportunistically on a future dispatch.
- A `gpt-5.5` turn at or above 272K active context. Harnex deliberately leaves
  price-table cost null there until exact long-context rates can be represented.
- Claude structured usage/cache-write capture or Claude cost (#58 remains open).
- A live three-dispatch retry/fallback chain; chain derivation is deterministic
  fixture coverage only.
- Multi-hour queue workload, macOS/other cross-platform behavior, or #64
  observed-state receipts / #57/#59 deterministic queue mechanics.
