# Harnex 0.15.0 — local-only verification

Date: 2026-10-16. Source: `81c6cb898910fd51aeecfd7edddb041157afe1a7`.

Source exposure: none — implementation, synthetic tests, packaging and
installation were local. No Git push, tag, RubyGems publication or public
artifact transfer occurred. Live checks dispatched short Pi sessions in
throwaway scratch repositories only; no product repository was touched.

## Changes

- **#70** Pi RPC receipts attest built-in `bash` commands: bounded command text
  and integer `result.structuredContent.exit_code`, correlated by `toolCallId`.
  Calls without structured exit evidence are counted in
  `observed.commands_unobserved`; `command_observation` gains `partial`;
  `validation.status` reads `unknown` instead of `pass` while any exist.
  Doctor advertises `capabilities.pi_command_proof: 1`.
- **#75** `wait`/`watch` observers survive a sibling registry file vanishing
  between the session scan's glob and read; doctor's sweep likewise.
