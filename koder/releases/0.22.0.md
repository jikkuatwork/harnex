## Changes

- **Lanes:**
  - `harnex delegate [--worktree NAME]`, `result`, `reply` (busy follow-up
    or Pi session resume), `land`, `discard` and `lanes`;
  - lane records in `STATE_DIR/lanes/`;
  - every ask is a lane, and `ask --resume` is an alias of `result`.
- **Breaking:**
  - `ask` defaults to `--timeout 9m`;
  - Pi starts with `--no-approve` unless `--approve` is passed.
- `wait --since`; `.harnex/` added to the clone's `info/exclude` on any
  dispatch-row write; `doctor` capability `lanes`.
- Help, `agents-guide claude`, and the `harnex` skill lead with the lane
  verbs; Codex-era `cx-` help examples are renamed.
