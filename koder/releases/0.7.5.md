# harnex 0.7.5 — release verification

- **Released:** 2026-05-26
- **Commit:** `d0a9dd0`
- **Tag:** `v0.7.5`
- **Headline changes:** #48 terminal-summary canonical completion detection. Added `Harnex::TerminalStatus`; `harnex status --json --id` now emits durable `running|completed|failed|unknown` state for inactive sessions; `harnex wait` now resolves completion/failure from summary/history when registry and exit-status files are absent. Monitoring guides demote `/tmp/*-done.txt` to legacy compatibility hints.

## Long-run telemetry

No multi-hour or overnight dispatch run was executed for this release. Telemetry validation focused on short deterministic terminal-state checks (summary-only completion and no-summary unknown behavior) plus full suite coverage.

## What this verification did NOT cover

- Long-running session behavior under repeated disconnect/reconnect conditions.
- Queue-runner-specific sweeper implementations outside harnex (Holm orchestration scripts remain external consumers).
- Pi PTY/TUI marker work (#45), Codex orchestrator recovery (#42), and queue-aware telemetry contract planning/implementation (#47).
- Cross-platform behavior (Linux-only validation in this release).
