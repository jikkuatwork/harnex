# Harnex 0.20.0 — local-only verification

Date: 2026-10-20. Local install only (owner decision 2026-10-18); no RubyGems
publication, tag or push. Owner decision 2026-10-20: "feel free to drop codex
— we are going to be exclusively pi & gpt models"; scope confirmed as "remove
it from harnex" (adapters, transport, flags, docs, tests).

## Changes

- Removed: `codex` and `codex app-server` adapters, the `stdio_jsonrpc`
  transport and app-server client, `run --fast` / `--legacy-pty`, Codex
  service-tier forcing, `preflight --legacy-pty`, Codex `doctor` checks,
  `docs/codex-appserver.md`, Codex fixtures/schema-drift/contract tests.
- `harnex doctor` checks Pi by default and only Pi; capabilities add `ask`,
  `final_message`, `owner_tag`.
- Shared behavior formerly covered through Codex is now covered through Pi
  or adapter-neutral fakes: receipts and claims, completion-notification
  ordering and races, boot-failure classification, stop sequencing,
  auto-stop, status fields, usage pricing, dispatch-row schema, and
  `harnex preflight` end to end (a fake Pi RPC process replaces the fake
  app-server).
- All docs Pi-only: README, GUIDE, TECHNICAL, guides, recipes,
  `docs/dispatch-telemetry.md`, `docs/pi-rpc.md`, repo `CLAUDE.md`
  (`pi-<role>-<tag>` ids). Issues #40 #42 #43 closed.
- Dispatch-row schema unchanged; Codex-only fields stay `null` in new rows.

## Evidence

- Full Ruby suite at the release source: **787 runs, 3,916 assertions**, zero
  failures/errors, one opt-in live-provider skip. (0.19.0 had 959 runs; the
  difference is removed Codex protocol/fixture tests. Shared-logic tests were
  ported, not dropped.)
- `grep -i codex` over shipped code and docs: only the removal note in
  `CLAUDE.md` and GPT model ids such as `gpt-5.3-codex` in the price table.
- Installed: `harnex --version` → `0.20.0 (2026-10-20)`; 66 shipped files
  match the source byte for byte; installed adapters are `base`, `claude`,
  `generic`, `opencode`, `pi`; `harnex doctor` → checks `["pi"]`, ok;
  `harnex run --help` mentions no Codex flag.
- Installed-CLI live smoke (Pi 1.3.0, `gpt-6.1-sol`): `harnex run pi --tmux
  --cwd <worktree> --root <repo> --context-file … --context-section Task
  --auto-stop --wait-done --wait-timeout 9m` → `done` in 51s,
  `final_message` "DONE 03a28e4" matching the lane commit, `turn_commits` 1;
  `harnex ask` from the lane answered correctly in 9s.
