# harnex 0.7.11 — release verification

- **Released:** 2026-07-10
- **Commit:** `7cb87a1`
- **Tag:** `v0.7.11`
- **Headline changes:** First-class queue-aware telemetry flags and top-level `queue`, `agent`, and `reliability` dispatch summary blocks for #47.
- **Status:** Superseded by `harnex 0.7.12` during installed smoke verification. The gem and tag were already published before the smoke exposed a reliability-block nuance for generic PTY no-summary exits.
