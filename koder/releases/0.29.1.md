# Harnex 0.29.1 — verification and publication

Date: 2026-10-23, verified as a local install. Published 2026-10-25 with the
owner's OK (see Publication). Fixes #88.

## Changes

- The runs behind lanes carry `meta.phase`: `delegate` or `ask` by
  default. Like `preflight`, these harnex-owned phases pass any repo phase
  allowlist, including one with `"policy": "reject"`.
- `harnex delegate --phase NAME` and `harnex ask --phase NAME` name a work
  phase instead. The allowlist checks it, and `reply` reuses it.
- A launch refused before the worker started leaves no lane record or
  brief. A refused `reply` restores the lane's previous state. `delegate`
  clears a record that 0.29.0 left this way, so the name can be reused.
