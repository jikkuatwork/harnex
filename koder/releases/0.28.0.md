# Harnex 0.28.0 — local-only verification

Date: 2026-10-22. Local install only (#87). This is the build that met the
plan 39 smoothness bar.

## Changes

- The MCP `ask` description, `harnex ask --help` and the skill index say
  that an ask worker only reads and cannot run commands; use `delegate` to
  run things.
- Outside this repo: the `gpt` relay sends briefs that run something or
  change files to `delegate` (in place), and questions and reviews to
  `ask`; `mode: read` forces read-only.
- Evals: `bin/slow-bench` prints a random score recorded in
  `.git/bench-last-score`. S4 and S6 pass only when the benchmark ran and
  the answer quotes that score.

## Did not cover

- **Supervisor models:** Opus or Haiku as the supervising Claude (the evals
  used Sonnet 5.5); Pi on models other than gpt-6.1-sol.
- **Rate limits during a write lane:** a real provider rate limit in the
  middle of a write lane. It was covered by `reply --model` live with a 404
  model, and by an ask fallback with a real luna rate limit (0.21.0).
- **Scale:** more than about 14 concurrent Pi workers; repos with large
  test suites or dependencies that worktrees would need to bootstrap
  (`.env`, `node_modules`).
- **macOS:** inotify-free platforms, and Claude Code channels.
