# Harnex 0.23.0 — local-only verification

Date: 2026-10-22. Local install only (#87).

## Changes

- `harnex mcp`: a stdio MCP server exposing `ask`, `delegate`, `result`,
  `reply`, `land`, `discard` and `lanes` (progress notifications,
  concurrent calls, cancel stops the wait only).
- `harnex mcp install|uninstall|status` for Claude Code (user scope) and Pi
  (`~/.pi/agent/mcp.json`, exposure `direct`, 7200s request timeout); it
  registers the RubyGems wrapper path.
- Lane verbs accept `harnex run` habits (`--id`, `--tmux`, `--auto-stop`,
  `--wait-done`, `--wait-timeout`, `--context`, `--context-file`).
- Outside this repo (`~/Projects/pi`):
  - the `gpt` agent is now a Haiku relay over the MCP tools (no Bash);
  - Pi's AGENTS.md visible-tmux directive notes that the lane verbs satisfy
    it;
  - the git-worktree skill says it is not needed for harnex lanes;
  - the skill index adds a row for tasks that don't edit.

## Evidence

- Suite at the release source: **811 runs, 4,168 assertions**, 0 failures.
- Installed `0.23.0`; 84 files match. `harnex mcp install` registered
  both clients:

  - `pi mcp list` → `harnex: connected, 7 tools (direct, global)`.
