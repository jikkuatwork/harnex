# harnex 0.11.0 — release verification

- **Released:** 2026-08-14 | 01:10 PM | IST
- **Commit:** `84237b7`
- **Tag:** `v0.11.0`
- **Headline changes:** Production hardening for Pi's current structured RPC
  contract. Pi >= 0.80.4 now completes only on `agent_settled`; Pi 0.84
  delta-only message updates stream without duplication; terminal stop reasons
  fail closed; model/thinking startup policy is verified without mutating Pi
  defaults; forced busy sends steer; request waits, stderr diagnostics, and
  child status are bounded. `harnex doctor --adapter pi` and
  `docs/pi-rpc.md` make the compatibility contract explicit.
- **Bounded release-gate compatibility work:** Codex 0.147.0 schema fixtures
  were refreshed after semantic review. Drift was one string path-alias
  replacement plus additive optional thread/item fields not consumed by
  Harnex; no Codex runtime behavior changed.
- **Verified against:** published and locally installed
  `harnex 0.11.0 (2026-08-14)`, Pi `0.84.1`, and Codex CLI `0.147.0` schemas.

## Long-run telemetry

No multi-hour or overnight dispatch was run for this release. Live coverage was
intentionally bounded to protocol and installed-binary smokes:

- real Pi 0.84.1 RPC lifecycle contract;
- successful repo-local and installed-gem auto-stop turns;
- explicit model/thinking policy with settings-preservation proof;
- invalid-model startup failure with a nonzero verdict and bounded stderr.

All successful live Pi turns reached `agent_settled`, published
`task_complete`, exited cleanly under auto-stop, and reported observed context
telemetry. No live disconnection was observed in these short runs.

## What this verification did NOT cover

- No induced live provider retry, overflow compaction, queued continuation, or
  forced steering turn; those settlement paths are covered hermetically.
- No long-running, parallel, overnight, or reconnect-stress Pi dispatch.
- No runtime Codex model turn. Codex work was deliberately limited to the
  release-blocking 0.147 schema compatibility review and contract suite.
- No Pi 0.80.4 live binary; minimum-version behavior is unit-covered, while
  live verification used Pi 0.84.1.
- No native Pi TUI/PTTY mode (#45), structured session recovery (#42), or full
  extension-dialog mediation.
- Linux only; no macOS, BSD, or Windows verification.
