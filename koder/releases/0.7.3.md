## Long-run telemetry

No multi-hour or overnight dispatch was run for this narrowly scoped
release. The release did not generate real Codex DISPATCH-row cost or
disconnect telemetry; the installed-binary smoke used a local JSON-RPC
stub to verify argv construction only.

The last long-run JSON-RPC reconnect/token-capture baseline remains
`koder/releases/0.6.5.md`. Re-run a long Codex dispatch before treating
0.7.3 as a new reconnect-stress baseline.
