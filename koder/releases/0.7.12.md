## Long-run telemetry

No multi-hour or overnight dispatch run was executed for this release. Telemetry validation focused on summary shape and queue/reliability semantics using deterministic short-lived Ruby children. No meaningful token/cost metrics were produced.

- Real Codex/Pi model turns using queue attribution flags.

- Artifact sidecar behavior beyond the 0.7.10 coverage.
- Pi PTY/TUI marker support (#45).
- Codex orchestrator recovery (#42) or deployment fallback work (plan 30 Phases 3–5).
- Cross-platform behavior (Linux-only validation in this release).
