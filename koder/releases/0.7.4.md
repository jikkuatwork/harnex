## Long-run telemetry

No multi-hour or overnight dispatch was run for this release. The live telemetry covered four short Pi RPC dispatches total during release validation:

- three repo-local pre-release smokes: simple response, bash tool, read tool
- one installed-binary post-release smoke: simple response

Observed behavior: all Pi RPC dispatches reached `task_complete`, exited successfully under `--auto-stop`, populated structured token/cost/model telemetry, and left no observed live tmux/session residue.

## What this verification did NOT cover

- Long-running Pi sessions, long-running Codex sessions, or reconnect-stress behavior.
- Pi PTY/TUI support; that remains deferred to issue #45 and stable extension-provided markers.
- Parallel live Codex + Claude + Pi dispatch in one run. The harnex control plane supports separate IDs/ports/logs, but this release validation only ran Pi live smokes.
- Cross-platform behavior. Linux only.
- Provider-side billing reconciliation beyond adapter-reported Pi `get_session_stats.cost`.
- Codex deployment-fallback plan 30 Phases 3–5 and issue #42 orchestrator recovery.
