# harnex 0.7.6 — release verification

- **Released:** 2026-06-09
- **Commit:** `ababf43`
- **Tag:** `v0.7.6`
- **Headline changes:** #50 Holm-blocking work-completion footgun fix. `harnex status --json` now exposes `process_state`, `task_complete`, `done`, and `work_state` so monitors can distinguish completed work from a still-live interactive process. `harnex wait --until done` resolves on `task_complete` or terminal exit, and bundled monitoring/buddy/recipe examples no longer gate on `state=completed` alone.
- **Verified against:** locally-installed `harnex 0.7.6 (2026-06-09)` via `gem install harnex`.

## Long-run telemetry

No multi-hour or overnight dispatch run was executed for this release. Telemetry validation focused on deterministic status/wait completion semantics and installed-binary smoke checks for the Holm blocker.

## What this verification did NOT cover

- Queue-runner-specific sweeper implementations outside harnex; Holm still needs to consume `done` / `work_state` / `--until done`.
- Long-running session behavior under repeated disconnect/reconnect conditions.
- Pi PTY/TUI marker work (#45), Codex orchestrator recovery (#42), and queue-aware telemetry contract planning/implementation (#47).
- Cross-platform behavior (Linux-only validation in this release).
