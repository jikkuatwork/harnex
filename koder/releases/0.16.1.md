# Harnex 0.16.1 — local-only verification

Date: 2026-10-18. Source: `4e365123232c66a459b1d64063c79a7d3219cdf6`.

Local install only (owner decision 2026-10-18); no RubyGems publication, tag or
push. Live checks used short Pi dispatches in a throwaway scratch repository.

## Changes

- **#76** `harnex watch --stall-after DUR` / `wait --until done --stall-after
  DUR`: exit **4** (`wait_result: stalled`) after DUR without progress; the
  worker is left running, no marker, no `--stop-on-terminal`. Clocks:
  `activity` (latest turn-start/model/tool event during an active turn; Pi and
  other structured adapters) or `output_log` (PTY transcript idle). Shared
  predicate `Harnex::Stall` for #77. Design decisions are recorded in the issue.

## Evidence

- Full Ruby suite at the source above: **898 runs, 4,234 assertions**, zero
  failures/errors, three opt-in live-provider skips.
- Installed: `harnex --version` → `0.16.1 (2026-10-18)`; all 76 installed files
  match the source; stall/wait/watch suites (44 runs, 213 assertions) pass when
  loaded from the installed gem's `lib`.
- Live, Pi 1.3.0: a dispatch running a silent `sleep 45` (checkout) and
  `sleep 30` (installed CLI) tripped `watch --stall-after 20s` / `12s` at 24s /
  13s with `clock=activity` while the worker stayed busy. A follow-up `watch`
  returned 0 (`completed_with_proof`) when the turn completed. Pi emits no tool
  events during a silent command, so silent commands longer than DUR count as
  stalls, as decided.
