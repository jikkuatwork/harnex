## Long-run telemetry

No multi-hour or overnight dispatch run was executed for this release. Telemetry validation focused on deterministic short-lived Ruby children and the full unit/integration suite. The smoke run did not produce meaningful provider token/cost metrics because the wrapped generic Ruby process has no usage producer.

## What this verification did NOT cover

- Long-running production queue workloads.
- Real Codex/Pi/Claude model turns using the new provenance/context telemetry.
- External primary-orchestrator telemetry or generation rollups (#55).
- Live recovery/fallback producers for plan 30 / #42 / #43.
- Pi PTY/TUI marker support (#45).
- Cross-platform behavior (Linux-only validation in this release).
